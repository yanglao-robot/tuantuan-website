# 团团 · 居家陪伴机器人

让居家养老多一份陪伴，让远方子女少一份牵挂。

**访问网站：https://yanglao-robot.github.io/tuantuan-website/**

这是团团项目的公开展示网页仓库，包含页面代码与展示图片。原生 CAD、结构验证报告及团队内部资料仍保存在独立的私有仓库。

## 页面

- `index.html`：项目出发点、242 份问卷、四人团队、原型进展与计划功能。
- `daily-life.html`：回家相迎、午后聊照片、睡前收纳三个独居场景构想。
- `details.html`：灰米小猫与奶白硬壳切换、尺寸及 CAD 结构图片。
- `style.css`：全站样式和手机适配。
- `assets/`：商品、场景和 CAD 展示图片。

## 编辑与发布

直接修改 HTML 文字、CSS 样式或替换 `assets/` 图片。无需安装依赖或运行构建命令。提交至 `main` 后，GitHub Pages 从仓库根目录发布；`.nojekyll` 保持纯静态文件部署。

本机预览可在仓库目录运行 `python -m http.server 8765 --bind 127.0.0.1`，然后访问 `http://127.0.0.1:8765/`。

## 内容与阶段

当前确认的毛绒外观为灰米色小猫、黑色面屏、薄荷绿眼睛；居家场景使用奶白硬壳。商品与生活场景为 AI 生成的外观及使用构想，CAD 图片来自原型三维模型，均不代表功能已完成或产品已上市。

242 份问卷、四人团队和已完成调研、三维建模、采购清单梳理等信息来自团队提供的项目介绍。基础受控移动、语音提醒、基础姿态识别及家属联络按计划目标表述。结构仍为概念设计，实际硬件和制造需要进一步验证。

版式参考 [OnEarth / Land-book](https://land-book.com/websites/100272-onearth-community-and-non-profits-website-webflow-template) 的使命叙事与绿色调；页面代码与团团影像为本项目制作，未打包参考模板的商业代码或图片。
